**Admin Panel → Reports** (Admin only).

| Report | Contents |
|---|---|
| **Membership Summary** | **Total Families**, **Total Parish Members**, **Heads of Household**, **Spouses**, **Dependents** |
| **Household Membership Directory** | Each household: Member ID, head of household, spouse, mobile number, dependents |
| **Member Information Report** | Member details for the whole parish. **Sort by** last name or first name. **Print** or **Save as PDF** |

Each report is headed with the church’s name and shows **Generated on** and **Generated by**.

:::danger These are lists of personal information
A printed directory contains every member’s name and phone number. Print only what is needed, keep it in the office, and shred it when replaced. Never post it online or share it in group chats. See [Security habits](#/getting-started/security-basics).
:::
