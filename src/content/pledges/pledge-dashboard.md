The Pledge Dashboard is shown above the pledge list on **Treasurer → Pledges**. It is built for reporting a drive’s progress to leadership.

:::screenshot images/pledges/pledge-dashboard.png | The Pledge Dashboard: progress toward the goal, fulfilment and monthly collections
1 @ 25,36 Received and Still owed
2 @ 50,15 Goal progress and daily pace
3 @ 25,80 Monthly collections
:::

| Element | Meaning |
|---|---|
| **Received** | Payments allocated to pledges in this drive |
| **Still owed** | Pledged but not yet paid. “{amount} paid over” means some donors paid more than they pledged. |
| **Goal reached** / “needs {amount}/day for {days} days” | Progress toward the goal amount, and the daily pace needed to reach it by the end date |
| **Households giving** / **Members giving** | “{count} of {total} ({rate})”, plus anonymous gifts |
| **Fulfilment** | Percentage of pledged dollars received, with a **Fulfilment breakdown** (paid in full, part-paid, unpaid) |
| **Needs attention** | Pledges worth following up, for example unpaid ones |
| **Monthly collections** | Received per month |
| **Employer matches** | Given by members’ employers. **Not** included in Received or in any member’s pledge |
| **Compared with the previous drive** | Same measures for the last drive. “There is no earlier drive to compare with yet” for the first one |

If figures can’t refresh, the dashboard says “Couldn’t refresh — these figures are from the time shown above.” Reload the page later.

## Using it for leadership

- Quote **Received**, **Still owed** and **Fulfilment** with the date.
- Remember **Employer matches** are extra money for the church but are not members’ pledge payments.
- For a printed summary, use the browser’s print (Ctrl+P or ⌘P) on this tab, or the [Board Summary](#/reports/board-summary) for the whole budget.
